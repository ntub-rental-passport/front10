## 尚不能宣稱完成的範圍

- 真實付款、訂閱訂單與付款回呼：方案展示及前端流程不能證明已串接金流。
- 租補政府申請、審核進度與代送件：租補導覽／提醒不等同政府系統整合。
- LINE 真正綁定與通知：歷史模擬 URL 不能當作已正式串接的證據。
- 多副本工作佇列與獨立排程：目前有程序內排程與記憶體工作，需另行設計／驗證。
- 完整正式部署、備份還原、全模組 E2E：部署材料不完整，本輪亦未執行。

以上為文件與程式盤點的限制，不是本輪要修改應用程式的清單。新增整合後應按實際實作、測試及部署結果更新狀態。
